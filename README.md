# Банный комплекс «Карелия» — сайт

Одностраничный сайт банного комплекса «Карелия» (Йошкар-Ола, Советская ул., 47): русские бани на дровах с домиками, подогреваемый чан, мангал и казан, работа круглосуточно.

## Что на сайте

- Первый экран с анимацией пара и искр
- Прайс-лист с переключением «Большой / Малый дом» и подсветкой текущего тарифа
- Калькулятор стоимости с учётом смены тарифов и посуточной аренды
- Галерея-слайдер (стрелки, перетаскивание, свайп) и просмотр фото на весь экран
- Ссылки на отзывы в Яндекс Картах, 2ГИС и Google Картах
- Контакты, режим работы, карта Яндекса и маршруты

## Как запустить

Сборка не нужна: откройте `index.html` в браузере или выложите папку на любой хостинг (например, GitHub Pages).

## Как поменять цены, телефоны и ссылки

Все данные собраны в объекте `DATA` в начале файла [`js/main.js`](js/main.js).
